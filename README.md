# Trymax

Trymax is a responsive static website for Proctormax, an academic support service that helps learners prepare for exams and coursework.

## What the project does

The site presents:

- Exam preparation for GED, TEAS, HESI, ATI, CPNRE, REx-PN, and other assessments
- Tutoring, assignment support, online courses, and study materials
- Student success stories displayed in an interactive carousel
- Contact options through email and WhatsApp
- Responsive layouts for desktop and mobile screens

## Project files

- `index.html` - Page structure and content
- `style.css` - Responsive visual styling
- `script.js` - Success stories carousel behavior
- `nurse-image.jpg.jpg` - Website image asset

## How to run

This is a static website and does not require a build step or package installation.

1. Open `index.html` directly in a browser, or
2. Open the project folder in VS Code and use a local server extension such as Live Server.
